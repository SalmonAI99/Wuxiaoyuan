# 第01课 - 贪吃蛇大挑战

你要做一个真正的游戏：一只小蛇，吃苹果，越吃越长。

先别怕代码很长。你不用一次看懂。先把它跑起来，玩一局，再一段一段看明白，最后改它。

如果你还没做完第 0 课，先回去：[[programming-lessons-zh/第00课-Linux和VSCode基础/第00课 - Linux 和 VS Code 基础|第00课：Linux 和 VS Code 基础]]。

## 0. 我们要做什么

1. **跑起来**：打开 `snake.py`，运行它，玩一局。
2. **看明白**：知道地图、蛇、苹果、移动是怎么写的。
3. **改一改**：接受大挑战，把游戏变成你自己的。

成功就是：你能自己运行游戏，说出蛇为什么会变长，还改了至少 1 个挑战。

新词预告（第一次见，记住它们）：

- **列表（List）**：一个购物清单，可以装很多东西，比如 `[[1, 2], [1, 3]]`。
- **循环（Loop）**：复读机，一句话重复说很多遍。`while True:` 就是“一直重复”。
- **坐标（Coordinate）**：电影院的座位号，比如第 2 排第 3 个。在这里记成 `[row, column]`。

这一步和第 0 课一模一样。忘记了就看：[[programming-lessons-zh/第00课-Linux和VSCode基础/安装指南 - 安装 VS Code 并运行 Python 你好世界|安装 VS Code 并运行 Python 你好世界]]。

### 第 2 步 - 建一个 `snake.py`

1. 在 VS Code 里点 **New File（新建文件）**。
2. 把下面这份完整代码粘进去（就是本课的 `snake.py`，一字不改）：

```python
from random import randint
game_map = []
print("Welcome to the game!")
rows = int(input("How many rows? "))
columns = int(input("How many columns? "))

# generate the game maps
for row in range(rows):
    game_map.append([])
    for column in range(columns):
        game_map[row].append("░░")

# pick the snake starting cordinate
snake_row = randint(0, rows - 1)
snake_column = randint(0, columns - 1)

snake_body = []
snake_body.append([snake_row, snake_column])

# pick the food cordinate
food_row = randint(0, rows - 1)
food_column = randint(0, columns - 1)

while True:
    # if the snake in our of the borders, the game end
    if snake_row < 0 or snake_row > rows - 1 or snake_column < 0 or snake_column > columns - 1:
        print("You lose!, since you can't teleport trough the walls")
        break
    # set the snake body
    for body_part in snake_body:
        game_map[body_part[0]][body_part[1]] = "██"

    # set the food
    game_map[food_row][food_column] = "🍎"

    # make every empty space a "░░"
    for row in range(rows):
        for column in range(columns):
            if [row, column] not in snake_body and [row, column] != [food_row, food_column]:
                game_map[row][column] = "░░"

    # print the game map
    for row in game_map:
        print("".join(row))
    print("\n")

    move = input("Enter your move: ")
    if move == "q":
        break
    elif move == "w":
        if [snake_row - 1, snake_column] in snake_body:
            print("You died!")
            break
        snake_body.append([snake_row - 1, snake_column])
        snake_row -= 1
        if [food_row, food_column] in snake_body:
            while [food_row, food_column] in snake_body:
                food_row = randint(0, rows - 1)
                food_column = randint(0, columns - 1)
        else:
            # remove the last body part if it's not eating the food
            snake_body.pop(0)

    elif move == "s":
        if [snake_row + 1, snake_column] in snake_body:
            print("You died!")
            break
        snake_body.append([snake_row + 1, snake_column])
        snake_row += 1
        if [food_row, food_column] in snake_body:
            while [food_row, food_column] in snake_body:
                food_row = randint(0, rows - 1)
                food_column = randint(0, columns - 1)
        else:
            snake_body.pop(0)

    elif move == "a":
        if [snake_row, snake_column - 1] in snake_body:
            print("You died!")
            break
        snake_body.append([snake_row, snake_column - 1])
        snake_column -= 1
        if [food_row, food_column] in snake_body:
            while [food_row, food_column] in snake_body:
                food_row = randint(0, rows - 1)
                food_column = randint(0, columns - 1)
        else:
            snake_body.pop(0)

    elif move == "d":
        if [snake_row, snake_column + 1] in snake_body:
            print("You died!")
            break
        snake_body.append([snake_row, snake_column + 1])
        snake_column += 1
        if [food_row, food_column] in snake_body:
            while [food_row, food_column] in snake_body:
                food_row = randint(0, rows - 1)
                food_column = randint(0, columns - 1)
        else:
            snake_body.pop(0)

    else:
        print("Invalid move!")
        continue
```

3. 按 `Ctrl + S` 保存，名字叫 `snake.py`。一定要以 `.py` 结尾。

## B. 它是怎么工作的？（详细拆解）

把游戏想成 3 样东西：**棋盘 + 小火车 + 苹果**。

- **棋盘 `game_map`**：一个大表格，每个格子放一个符号。
- **小火车 `snake_body`**：一个列表，装着蛇每一节的坐标。车头往前开，吃到东西就加一节，不然就丢掉最后一节。
- **苹果 `[food_row, food_column]`**：一个坐标，藏在棋盘上。

游戏就是一个大循环：画图 → 问你往哪走 → 动一下 → 再画图。

### B1. 建棋盘（第 1–11 行）

```python
from random import randint
game_map = []
rows = int(input("How many rows? "))
columns = int(input("How many columns? "))
for row in range(rows):
    game_map.append([])
    for column in range(columns):
        game_map[row].append("░░")
```

- `from random import randint`：请一个“随机数小帮手”来。它能从一个范围里随便挑一个数。
- `game_map = []`：先拿一个空盒子，准备装棋盘。
- `input(...)`：停下来问你一句话，等你打字。`int(...)` 是把你打的字变成数字。
- 下面的两层 `for`：外层一行一行建，内层一格一格填 `░░`。`5` 行 `7` 列就是 35 个 `░░`。

生活例子：先拿一个空抽屉柜，再一个格子一个格子铺上灰布。

### B2. 放蛇和苹果（第 13–22 行）

```python
snake_row = randint(0, rows - 1)
snake_column = randint(0, columns - 1)
snake_body = []
snake_body.append([snake_row, snake_column])
food_row = randint(0, rows - 1)
food_column = randint(0, columns - 1)
```

- `randint(0, rows - 1)`：在 0 到最大之间随便挑。比如 5 行，就是 0、1、2、3、4 里挑一个。
- `snake_body = [[snake_row, snake_column]]`：一开始蛇只有 1 节，就是它的出生点。
- 苹果也是随便挑一个坐标。

注意一个小秘密：苹果有可能正好出生在蛇身上。后面挑战里我们要修好它。

### B3. 大循环和撞墙（第 24–28 行）

```python
while True:
    if snake_row < 0 or snake_row > rows - 1 or snake_column < 0 or snake_column > columns - 1:
        print("You lose!, since you can't teleport trough the walls")
        break
```

- `while True:`：复读机开始，一直重复下面的事，直到有人喊停。
- `if ...`：检查车头有没有开出棋盘。`break` 就是“跳出循环，游戏结束”。
- 墙是不能穿的，和打游戏一样。

### B4. 画图（第 29–45 行）

```python
for body_part in snake_body:
    game_map[body_part[0]][body_part[1]] = "██"
game_map[food_row][food_column] = "🍎"
for row in range(rows):
    for column in range(columns):
        if [row, column] not in snake_body and [row, column] != [food_row, food_column]:
            game_map[row][column] = "░░"
for row in game_map:
    print("".join(row))
```

分 4 小步：

1. 把蛇的每一节涂成 `██`。
2. 把苹果涂成 `🍎`。
3. 其他格子都涂回 `░░`，擦掉上一轮的脚印。
4. 一行一行打印出来。`"".join(row)` 就是把一行的格子粘成一串再打印。

为什么要第 3 步？因为棋盘是同一张纸重复画的，不擦干净会有重影。

### B5. 走路和长大（第 47–101 行，以 `w` 为例）

```python
move = input("Enter your move: ")
if move == "q":
    break
elif move == "w":
    if [snake_row - 1, snake_column] in snake_body:
        print("You died!")
        break
    snake_body.append([snake_row - 1, snake_column])
    snake_row -= 1
    if [food_row, food_column] in snake_body:
        while [food_row, food_column] in snake_body:
            food_row = randint(0, rows - 1)
            food_column = randint(0, columns - 1)
    else:
        snake_body.pop(0)
```

`s`、`a`、`d` 和 `w` 一模一样，只是方向不同：

- `w`：`snake_row - 1`，行号减 1，向上。
- `s`：`snake_row + 1`，行号加 1，向下。
- `a`：`snake_column - 1`，列号减 1，向左。
- `d`：`snake_column + 1`，列号加 1，向右。

以 `w` 为例，记住 4 步：

1. **先看会不会咬到自己**：下一格已经在 `snake_body` 里，就打印 `You died!`，结束。
2. **加车头**：`append(...)` 把新位置加进列表。再把 `snake_row` 减 1，记住车头搬家了。
3. **吃到苹果就长大**：如果苹果的坐标也在蛇身体里，说明吃到了，重新找一个不在蛇身上的苹果。这次不丢尾巴，所以蛇变长 1 格。
4. **没吃到就保持长度**：`pop(0)` 丢掉第 0 节（最老的尾巴）。加一头、丢一尾，长度不变，看起来就是往前爬。

生活例子：小火车有 3 节车厢。往前开时，前面加一节新的，后面丢掉一节旧的。吃到苹果那次，后面不丢，就变成 4 节了。

`q` 是直接 `break`，退出。其他乱按的字母会进 `else`，打印 `Invalid move!`，重新问你。

### 一句话总结

地图是纸，蛇是坐标清单，苹果是一个点。每次循环做：检查撞墙 → 画纸 → 问方向 → 加头（吃到就不去尾）。就这么简单。

## C. 大挑战（从 ⭐ 到 🚀）

规则：一次只改一点点，改完马上运行。每次运行都用：

```bash
python3 snake.py
```

### ⭐ 挑战 1 - 换皮肤（必做，2 分钟）

把 `░░` 换成 `··`，把 `██` 换成 `OO`，把 `🍎` 换成 `★`。

- 要改哪里：B4 画图的三处符号。
- 成功长这样：地图还是 5×7，但全是你的新符号，还能正常玩。
- 提示：用 VS Code 的替换（`Ctrl + H`），别一个一个敲。

### ⭐⭐ 挑战 2 - 显示分数（推荐）

每次画完地图，加一行分数。分数 = 蛇的长度减 1（刚出生 1 节，0 分）。

在打印地图的后面加一行，比如：

```python
print("Score:", len(snake_body) - 1)
```

- `len(...)` 是数一数列表里有几样东西。
- 成功长这样：每走一步都看到 `Score: 0`、`Score: 1`……吃苹果后分数变大。
- 再进一步：游戏结束时也打印一次最终分数。

### ⭐⭐⭐ 挑战 3 - 苹果不许出生在蛇身上（修 bug）

现在苹果可能出生在蛇身上，一开局就“被吃”了。

在 B2 放苹果后加一个检查：如果苹果在蛇身上，就重新挑，直到不在为止。

```python
while [food_row, food_column] in snake_body:
    food_row = randint(0, rows - 1)
    food_column = randint(0, columns - 1)
```

- 成功：连开 5 局，开局分数都是 0，不会一开局就变长。
- 想一想：游戏里吃到苹果后已经有这段代码了（B5 第 3 步），为什么开局时作者忘了？

### ⭐⭐⭐ 挑战 4 - 说中文 + 不怕乱输入

把三句英文换成中文：

- `Welcome to the game!` → `欢迎来到贪吃蛇！`
- `Enter your move: ` → `走哪边？(w上 s下 a左 d右 q退出)：`
- `Invalid move!` → `只能按 w a s d q 哦，再试一次！`

成功：全程中文也能玩，乱按 `x`、`1`、回车也不会死机，只是提醒你重输。

### ⭐⭐⭐⭐ 挑战 5 - 清屏 + 计步器（像真正的游戏）

现在地图越打印越长，眼睛会花。加两样：

1. 每次画图前清一下屏。在文件最上面加 `import os`，在 `while True:` 里面第一行加：

```python
os.system("clear")
```

在 Windows 上是 `os.system("cls")`，Ubuntu 用 `clear` 就行。

2. 数一数走了几步。在循环前面加 `steps = 0`，每次移动后加 `steps = steps + 1`，再打印出来。

成功：每次只看到一张干净的地图，下面写着步数和分数。

### 🚀 终极挑战 6 - 毒蘑菇（选做，给哥哥检查）

加一个 💀，吃到就输。

思路（自己试着写，写不出来就问哥哥）：

1. 像苹果一样随机放一个 `poison_row, poison_column`，也要保证不在蛇身上、不在苹果上。
2. 画图时把它画成 `💀`。
3. 移动后检查：如果毒蘑菇的坐标在 `snake_body` 里，就打印 `You ate poison!`，`break`。
4. 苹果被吃掉会重生，毒蘑菇被吃就直接结束，不用重生。

成功：能正常吃苹果长大，但撞到 💀 马上结束。把你的代码拿给哥哥看，说出你是怎么想的。
