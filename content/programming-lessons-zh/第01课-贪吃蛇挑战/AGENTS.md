- 读者还是完全零基础的小学生，只学过第 0 课的 `print` 和运行。
- 语气鼓励、亲切。短句子。每个新词第一次出现都要解释（列表、循环、坐标）。
- 代码、文件名、命令保持英文原文，只讲中文解释。
- 主文档结构：我们要做什么 → A 轻松上手（5 步跑起来）→ B 它是怎么工作的（逐段拆解）→ C 大挑战（分星级）→ 成功检查。
- 终端命令要完整 + 写出应该看到什么。
- 不要一次教太多 Python，只讲读懂 `snake.py` 必须的几样。
