# AGENTS.md — 第02课-Python基础语句

第 2 课中文版。目标：学会 `if`、`for`、`while`，能读懂贪吃蛇里的判断和循环。

- 读者是小学生，已做完第 0 课和第 1 课（跑过 `snake.py`，见过 `while True`）。
- 语气鼓励、亲切。短句子。每个新词第一次出现都要解释（条件、缩进、范围）。
- 代码、文件名、命令保持英文原文，只讲中文解释。
- 主文档结构：我们要做什么 → A 轻松上手（跑猜数字）→ B 逐段拆解（if / elif / else / for / while / break）→ C 大挑战（分星级）→ 成功检查。
- 终端命令要完整 + 写出应该看到什么。
- 对比表格多用：`==` 和 `=` 的区别、`for` 和 `while` 什么时候用。
- 常见报错必须讲：缩进错误、忘记冒号、死循环怎么停（`Ctrl + C`）。
