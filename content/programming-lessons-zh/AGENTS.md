# AGENTS.md — programming-lessons-zh

给弟弟的编程入门课中文版。读者是中国小学生，完全零基础。目标：Ubuntu 24.04 LTS。

- 这是 `programming-lessons` 的中文镜像，文件和文件夹结构保持一致。
- 语言：简体中文，短句子，生活中的例子。每个新词第一次出现都要解释。语气鼓励、亲切，不要用专业黑话。
- 每课结构：我们要做什么，分几小步，一个小动手任务，怎么做算成功。
- 先用鼠标点（图形界面），再用终端。需要终端时，给出完整命令 + 应该看到什么。
- 不要假设会编程、会终端、会 VS Code。
- 命令、文件名、代码保持英文原文不变，只把讲解翻译成中文。
