# 你好世界练习

你已经很棒了。现在自己改几小下，试试看。

还是用同一个文件：`hello.py`。

## 练习 1 - 改一改文字

把代码改成：

```python
print("Hello Thomas")
```

运行它。

成功时会看到：

```
Hello Thomas
```

## 练习 2 - 说两句话

把代码改成：

```python
print("Hello world")
print("I am learning Python")
```

运行它。

成功时会看到：

```
Hello world
I am learning Python
```

## 练习 3 - 改成你自己的话

把代码改成和你自己有关的内容：

```python
print("My name is ____")
print("My favorite game is ____")
```

把空白补上，再运行一次。

- [ ] 我会重新运行，并看到新的结果
