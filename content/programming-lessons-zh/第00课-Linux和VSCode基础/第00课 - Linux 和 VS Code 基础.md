# 第00课 - Linux 和 VS Code 基础

欢迎！这一课就是随便看看。你不用全部记住。你只要知道：我的文件在哪里，终端是什么，VS Code 是什么。

准备好就去下一步：[[安装指南 - 安装 VS Code 并运行 Python 你好世界]]。

## 1. 什么是 Ubuntu Linux？

把电脑想成一座房子。

- **Ubuntu** 就是这座房子。Windows 和 macOS 是另外的房子。Ubuntu 是免费的，学编程的人很喜欢用它。
- **文件** 就像衣服。**文件夹** 就像抽屉。一个抽屉可以装衣服，还可以装小盒子。
- 所有的东西都在一个大衣柜里，大衣柜从 `/` 开始。你的东西在 `/home/你的名字` 里，也叫 **Home（家目录）**。

你其实已经会用了：点一点，打开文件夹，搬动文件，这就是 Linux。

试一试：
1. 点左边栏的 **Files（文件）**。
2. 进到 **Home**。
3. 新建一个文件夹：点右键 > New Folder（新建文件夹），名字叫 `my-first-code`。

好啦！你刚才就用了一次 Linux。

## 2. 什么是终端（Terminal）？

**终端** 就是用打字和电脑说话，不用鼠标点。

就像给电脑发短信。你写一句话，按回车，它就回你一句。

不用害怕它。程序员喜欢用它，因为有时候打字比点鼠标更快。

安全地试一试：
1. 按 `Ctrl + Alt + T`。会弹出一个黑窗口，这就是终端。
2. 输入下面这行，按回车：
   ```bash
   pwd
   ```
   它会告诉你现在在哪里，比如 `/home/你的名字`。`pwd` 就是“我是哪里？”的意思。
3. 输入下面这行，按回车：
   ```bash
   ls
   ```
   它会列出这个文件夹里有什么，就像打开抽屉看一眼。
4. 输入下面几行，进到你刚才的新文件夹，再看一眼：
   ```bash
   cd my-first-code
   pwd
   ls
   ```
5. 如果屏幕太乱了，输入 `clear`，按回车。它只是把窗口擦干净。

现在只要记住 4 个单词：`pwd`、`ls`、`cd`、`clear`。

> 规则：如果它让你输入密码，还出现 `sudo`，先停下来，去问哥哥。

## 3. 什么是 VS Code？

**VS Code** 就像一个超级笔记本，专门写代码用的。

- 普通笔记本 = 写作业。
- VS Code = 写代码。它会给字涂颜色，帮你找错，还能运行你写的东西。

你以后会这样用它：
1. 在左边打字写代码。
2. 按一下运行。
3. 在右边或者下面看到结果。

现在不用学所有按钮。你只要会：打开文件夹、新建文件、打字、保存、运行。

## 4. 它们是怎么连起来的？

一张简单的图：

- **Ubuntu** = 房子。
- **文件** = 抽屉。
- **终端** = 给房子发短信。
- **VS Code** = 桌子上的笔记本。
- **Python** = 小帮手，它看你的笔记本，让电脑照着做。
