# AGENTS.md — programming-lessons

Beginner course for younger brother. Complete beginner to programming and Linux. Target: Ubuntu 24.04 LTS.

- One folder per lesson, self-contained.
- Language: very simple, short sentences, everyday examples. Explain every new word on first use. Encouraging tone, no jargon.
- Every lesson: what we will do, small steps, one tiny try-it task, what success looks like.
- Prefer GUI first, Terminal second. When Terminal is needed, give exact command + what it should print.
- Do not assume prior knowledge of programming, Terminal, or VS Code.
